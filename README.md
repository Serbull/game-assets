# Game Assets

## Responsive UI

Начиная с 1.3.0 пакет включает общий модуль Serbull Responsive UI: Portrait/Landscape, переключение F9 и сохранение альтернативных значений компонентов в префабах.

- Требуется Unity 6 (6000.0+) и Unity UI 2.0.0.
- Runtime: `Runtime/ResponsiveUI`; инструменты редактора: `Editor/ResponsiveUI`.
- Скрипты и сборки сохраняют исходные имена и GUID. Отдельную копию из `Assets/Serbull/ResponsiveUI` одновременно устанавливать нельзя.
- Варианты добавляются только выбранным компонентам; префабы автоматически не изменяются.

Настройка и переход с отдельного ассета: [ResponsiveUI.md](ResponsiveUI.md).
